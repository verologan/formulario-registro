# Formulario de Registro

Proyecto de un formulario de registro desarrollado con HTML y CSS.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## 📌 Descripción

Este proyecto consiste en la creación de un formulario de registro con una interfaz sencilla y responsive, utilizando HTML para la estructura y CSS para el diseño y los estilos.

## 🎯 Objetivo

Practicar la creación y estructuración de formularios web, así como mejorar el uso de HTML y CSS para crear interfaces atractivas y adaptables.
